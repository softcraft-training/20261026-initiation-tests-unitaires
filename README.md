# Tests unitaires et TDD

---

### Objectifs

- **Comprendre** les fondements des tests unitaires et leur rôle dans la qualité logicielle
- **Écrire** des tests unitaires efficaces : logique métier, validation d'entrées, cas limites, erreurs, valeur de retour, état et interactions
- **Appliquer** les méthodologies TDD et BDD
- **Automatiser** l'exécution des tests dans l'intégration continue
- **Assurer** une couverture suffisante et éviter les pièges courants (tests fragiles, faux positifs)
- **Analyser** les résultats des tests et interpréter les erreurs
